Chrome Recorder 使用步骤 内置工具 无需安装

打开 DevTools Recorder 面板

按 F12 打开开发者工具 → 顶部点 >> 展开更多面板 → 点击 Recorder

新建录制并开始

点击 Create a new recording → 填写名称 → 点 Start recording（红点亮起）

正常操作页面

像平时一样点击、填写、跳转页面。跨页导航会自动被记录，不会中断录制。

停止并导出 JSON

操作完成后点 End recording → 点右上角 ⋮ 菜单 → 选 Export as JSON → 保存到 网页自动化/ 目录

转换命令 一行命令

基础用法

# 在 网页自动化/ 目录下运行
python chrome_recorder_to_selenium.py 录制文件.json

# 指定输出文件名
python chrome_recorder_to_selenium.py 录制文件.json -o 查询导出流程.py
生成的 Python 文件包含：自动等待加载、多选择器依次尝试、异常报告具体是哪个选择器失败、最后按 Enter 才关闭浏览器（方便观察结果）。
生成的 Python 脚本示例
# 步骤 1: navigate → https://example.com/report
driver.get("https://example.com/report")
wait_load(driver)

# 步骤 2: change  [select#report-type]
el = find_el(driver, [('CSS_SELECTOR', 'select#report-type'),
                       ('XPATH', '//select[@id="report-type"]')])
if el.tag_name.lower() == 'select':
    Select(el).select_by_visible_text("月报")
time.sleep(0.3)

# 步骤 3: click  [#query-btn]
find_el(driver, [('CSS_SELECTOR', '#query-btn'),
                 ('XPATH', '//button[@id="query-btn"]'),
                 ('XPATH', '//*/[normalize-space(.)="查询"]')]).click()
time.sleep(0.5)
自动化插件的辅助用途 局部补充

循环遍历下拉列表

Chrome Recorder 不支持循环，用插件录制"选下拉 → 查询 → 导出"一个循环体，导出 JSON 后让 Claude 补全 Python 循环逻辑。

获取精确选择器

用插件的元素拾取器（橙色边框）选中目标元素，可以看到 ID、widgetname、CSS 路径等多个选择器，复制给 Python 脚本用。

FineReport 专项操作

内网 FineReport 系统有专属 API（_g().exportReportToExcel），插件内置了这个步骤类型，比 Selenium 点击导出按钮更可靠。
