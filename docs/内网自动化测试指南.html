内网 Chrome 自动化测试工作流

🔍

Console（控制台）

Chrome 内置

用来快速验证选择器，确认能不能找到目标元素。

  • 按 F12 打开
  • 切到 Console 标签
  • 直接输入 JS 回车运行
  • 支持进入 iframe 上下文
📝

Snippets（代码片段）

Chrome 内置

类似 Jupyter Notebook，可以保存多段脚本分块执行。

  • F12 → Sources → Snippets
  • 新建后写 JS，Ctrl+Enter 运行
  • 保存在本地，重启浏览器还在
  • 适合逐步调试完整自动化逻辑
🔌

录制插件

你自己的扩展

逻辑验证完毕后，用插件录制固化为可复用的自动化流程。

  • 不需要写代码
  • 支持循环列表、条件过滤
  • 支持 iframe 内操作（刚修复）
  • 一键回放

代码示例（Snippets 分步写法）

// 验证下拉框选择器是否正确
const dropdown = document.querySelector('select#report-type');
console.log(dropdown);         // null 说明选择器不对
console.log(dropdown?.value);   // 当前选中的值
// 读取所有下拉选项
const options = [...document.querySelectorAll('select#report-type option')];
console.log(options.map(o => o.textContent.trim()));
// 输出：["请选择", "日报", "月报", "年报"]
// 切换到某个选项并触发页面响应
const sel = document.querySelector('select#report-type');
sel.value = '月报';
sel.dispatchEvent(new Event('change', { bubbles: true }));

// 等待页面响应后，点击查询按钮
await new Promise(r => setTimeout(r, 1000));
document.querySelector('#query-btn').click();
// 完整循环：遍历每个选项 → 查询 → 导出
const sel = document.querySelector('select#report-type');
const opts = [...sel.options].filter(o => o.value !== '');

for (const opt of opts) {
  sel.value = opt.value;
  sel.dispatchEvent(new Event('change', { bubbles: true }));
  await new Promise(r => setTimeout(r, 1500)); // 等待查询结果

  document.querySelector('#export-btn').click();
  await new Promise(r => setTimeout(r, 2000)); // 等待下载

  console.log(`✅ 已导出: ${opt.textContent.trim()}`);
}
// 进入 iframe 内部操作
const iframe = document.querySelector('iframe#report-frame');
const iDoc = iframe.contentDocument;

// 在 iframe 里找元素
const btn = iDoc.querySelector('#export-btn');
btn.click();

// 如果跨域 iframe 无法访问 contentDocument，
// 需要在 DevTools 顶部的 frame 下拉框切换到目标 iframe 再运行
💡 Snippets 小技巧：在 DevTools 顶部左侧有一个下拉框可以切换执行上下文（默认是主页面，可以切换到某个 iframe），切换后 Console / Snippets 里的 document 就指向那个 iframe 的文档。
